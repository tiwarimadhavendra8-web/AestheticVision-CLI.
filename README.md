# AestheticVision CLI Engine

A command-line Computer Vision tool that applies mathematical image transformations to create stylized animation effects and high-contrast black-and-white portraits.

**Author:** Madhavendra Tiwari  
**Registration Number:** 24BAI10893  
**Institution:** VIT Bhopal University  

## Setup Instructions
1. Clone this repository to your local machine.
2. Ensure Python 3.x is installed.
3. Install the required dependencies:
   `pip install -r requirements.txt`

## Execution Instructions
This tool runs strictly via the command line.

**To apply the Animation style:**
`python main.py --input test.jpg --output result_animation.jpg --mode animation`

**To apply the High-Contrast Black & White style:**
`python main.py --input test.jpg --output result_bw.jpg --mode bw`
